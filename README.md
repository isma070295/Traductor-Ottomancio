# Traductor Ottomancio

**Traductor Ottomancio** is a custom translation program that translates text from the alphabet into the **Ottomancio language**. This language uses a custom alphabet that I designed, with unique mappings for letters, numbers, and symbols.

## Available Files

- **Traductor-Ottomancio-private.py**: This file contains the full program, including the translation algorithm and alphabet mappings. It is available only to me and is not shared publicly.
- **Traductor-Ottomancio-public.py**: This public version shows the general structure of the program, but it does not include the proprietary alphabet mappings. The logic for how the translation is made is explained in comments, but the exact mapping is omitted for intellectual property protection.
- **Traductor-Ottomancio.exe**: Desktop executable version of the translator, with full functionality (text translation, spoken pronunciation, and clipboard copy).
- **index.html**: Browser-based version of the translator, built to mirror the desktop app's functionality using HTML, CSS and JavaScript.
- **Ottomancio.ttf**: Custom font used to render translated text in the Ottomancio script, both in the desktop app and the web version.

## Web Version

A browser-based version of the translator is also available, requiring no installation:

**[https://isma070295.github.io/Traductor-Ottomancio/](https://isma070295.github.io/Traductor-Ottomancio/)**

It replicates the desktop app's core features (live translation, spoken pronunciation via the browser's speech engine, and copy to clipboard) and displays translated text using the custom Ottomancio font.

## How to Use

### Desktop
1. Download the executable file below.
2. Open the program and paste your text into the "Original Text" box.
3. Click the "Translate" button to get the translated text and pronunciation as audio.
4. You can also click the "Play Audio" button to hear the translation read out loud again.

### Web
1. Open the [web version](https://isma070295.github.io/Traductor-Ottomancio/) in your browser.
2. Type or paste your text into the "Texto original" box — the translation updates live.
3. Click "Reproducir pronunciación" to hear it read aloud, or "Copiar al portapapeles" to copy the translated text.

## Features

- Translates text to the Ottomancio alphabet.
- Converts letters, numbers, and some special characters.
- Contains a custom-designed font for display and output.
- Available both as a desktop executable and as a browser-based version.
